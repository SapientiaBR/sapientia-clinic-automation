# Sample slides

Seven slide types for commercial material (pitch deck, proposta), built directly on the tokens so they print and export cleanly at 1280×720.

| File | Type |
| --- | --- |
| `cover.html` | Emerald cover with organic blobs, mark + display headline |
| `section.html` | Numbered section opener on Medical Mint |
| `product.html` | Product explanation beside a WhatsApp conversation |
| `metrics.html` | Four big numbers as white cards on Ghost White |
| `comparison.html` | Antes / depois, white card vs. emerald card |
| `quote.html` | Two-weight pull quote with attribution |
| `closing.html` | Closing slide with contact capsules |

Rules carried over from the reference boards: at most two background colours per deck, numbered eyebrows ("03 // Como funciona"), footer with deck name and page count, display type at medium weight with -3.5% tracking.
