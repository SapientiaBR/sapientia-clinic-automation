# UI kit — Landing page de vendas

Recreation of secretariainvisivel.com.br in the reference brand's marketing language: emerald gradient hero with soft organic blobs, Medical Mint alternating band, numbered section eyebrows, pricing on white, ink-dark closing CTA, near-black footer.

| File | Contents |
| --- | --- |
| `LandingChrome.jsx` | `LandingNav`, `LandingFooter`, the `Blobs` background motif and the `Photo` placeholder |
| `LandingHero.jsx` | Emerald hero with a live WhatsApp conversation in a device-style frame |
| `LandingBody.jsx` | `HowItWorks` (01), `AgendaFeature` (02), `Results` (03), `Quote` |
| `LandingOffer.jsx` | `Pricing` (04), `Faq` (05, accordion), `FinalCta` |

The FAQ accordion is interactive. Photography is stubbed with dashed `Photo` placeholders — real imagery has not been supplied.

Copy is Brazilian Portuguese, consultative and specific, addressed to clinic owners.
